# Roadmap

`fasterhenry` is a clean-room, MIT-licensed Rust PEEC engine for resistance and
inductance extraction, built to replace FastHenry in existing flows.

Status as of 2026-11-13, `main` @ `8178cb7`.

[`WORK_PLAN.md`](../WORK_PLAN.md) is the tracker's queue, regenerated by the
Guide role. This file is the direction behind it: where the project stands,
what comes next and why.

## Where it stands

- **Engine.** Filament model with uniform, surface-graded and
  skin-depth-graded subdivision; ground planes with holes, graded contact
  regions and equipotential patches; coupling truncation; a dense complex
  solve and a precorrected-FFT + GMRES path the CLI switches to above
  10 000 filaments (`fasterhenry/src/`, README "Performance").
- **Evidence.** Agreement with PyPEEC, the Greenhouse closed forms and the
  skin-effect and ground-plane references is asserted in CI by positive
  gate markers ([`validation.md`](validation.md)). The SPICE export is
  checked in ngspice against the JSON impedance (#267). `perf_smoke` holds
  hard time and memory budgets on every run.
- **Releases.** 0.1.0 and 0.1.1 are on crates.io. The workspace version is
  0.2.0 and the 0.2.0 release PR (#262) has merged, but there is no `v0.2.0`
  tag and crates.io still lists 0.1.1 as the newest version, so **0.2.0 is
  not published**.
- **0.2.0 epic (#76).** Deck compatibility (#69 to #72), the drop-in CLI
  (#73) and the license gate (#75) are done. The field-by-field audit is
  [`fasthenry-compat.md`](fasthenry-compat.md). One child is open: the
  real-deck corpus comparison (#74).
- **Corpus.** The last recorded run parses 4 of 19 decks, at `9f4ecd8`
  ([`benchmarks.md`](benchmarks.md#fasthenry-example-corpus-74)). The gaps
  that run filed (#154 to #157) have since closed, as have #143, #145 and
  #146, and the corpus has not been rerun.
- **After 0.2.0.** Per-filament currents, current density and dissipated
  power with a power-balance check (#294, PR #296, `--currents`) are on
  `main` and missing from `CHANGELOG.md`.
- **Site.** fasterhenry.org is live with six pages (#243, operator note of
  2026-11-10). The redesign epic (#303) has landed its table, visual-system,
  chart, gallery, validation, benchmarks, contents and FastHenry-users
  children (#304 to #310, #312); the landing page (#311) is open.
- **Queue.** No open pull requests and no issue labelled `loom:issue`. Every
  open issue is blocked, operator-held or a tracker.
