This file is the attribution bundle for a **distributed `fasterhenry` binary**.
A binary links every crate below into the shipped artifact, and some of those
crates' licenses require that a recipient of the binary receive their license
text — most importantly Apache-2.0 §4(a), which the MIT `LICENSE` at the repo
root does not discharge on its own. Ship this file alongside any binary
artifact.

Coverage is the `normal` + `build` dependency closure of the workspace, for
every platform a binary might be built for, so one file serves every artifact.
Development-only dependencies (the `criterion` benchmark stack) are **not**
here: they are not linked into anything distributed. The workspace's own crates
appear in the table for completeness; their license is the repo's `LICENSE`.

`fasterhenry` itself is MIT-licensed. Nothing below changes that — these are the
terms of other people's code that a binary carries with it.
