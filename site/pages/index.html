fasterhenry

A clean-room, MIT-licensed Rust PEEC R/L extractor for 3-D conductors: FastHenry's problem class, none of its code.

Install

cargo install fasterhenry-cli

Then fasterhenry deck.inp. It reads FastHenry .inp decks and writes JSON, a MAT v4 Zc.mat, or a SPICE subcircuit.
