Clean room

This project never contains code derived from FastHenry or FastCap, in any branch or mirror. It is written from the published papers (Ruehli's PEEC formulation; Kamon, Tsuk and White's FastHenry paper) and from decks the contributors author themselves. Reading the .inp deck format is fine, because a file format is not code; CI fails the build if copied license text appears. The history is kept in the open on purpose: “full git history from an empty root; the paper trail is intentional.” The rule, in full, is in CONTRIBUTING.md.
